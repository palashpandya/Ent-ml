# Ent-ml
This repository has the objective of using Multi Layer Perceptron (MLP) broadly as non-linear optimizers. We do two things with them:
1.   New implementation of creating separable approximations or Closest Separable states for a given quantum state.
2.   Using MLP to discover Absolutely Maximally Entangled states.

- The implementation uses Tensorflow.
- The size of the quantum state defines the size of the MLP.
